# Adaptive Traffic Signal Optimization on Hadoop

A Hadoop-based Big Data framework for adaptive traffic signal
optimization using traffic analytics, congestion prediction,
multi-factor signal optimization, and emergency vehicle priority.

## Problem

Fixed-time traffic signals use predefined timings and cannot adapt
to changing traffic conditions, leading to unnecessary waiting,
longer queues, wasted signal time, and lack of emergency priority.

## Proposed Solution

Our framework processes large-scale traffic data using Hadoop and
uses the resulting analytics to predict congestion and optimize
signal timings for a four-way intersection.

## Architecture

Traffic Data
→ HDFS
→ MapReduce
→ Hive
→ Traffic Analytics
→ Prediction
→ Optimization Engine
→ Simulation
→ Evaluation

## Key Features

- Adaptive signal timing
